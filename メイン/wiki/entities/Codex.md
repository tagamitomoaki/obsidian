# Codex

OpenAI のコーディングエージェント（CLI・デスクトップ版、モデルは gpt-5.5→5.6 系）。Claude Code と並行運用している「もう一人の AI」。別モデルゆえ盲点が重ならない=**独立性がレビュー価値の源泉**。

## 配役の原則（2026-07-25 確定）

固定配役にせず、タスクごとに選ぶ。**「書いた本人だけがレビューしない」**。

- 仕様が明確で独立性の高いタスク → Codex に並行実装させ、Claude がレビュー・統合・コミット
- Claude が実装した変更 → Codex に diff+意図を渡してクロスレビュー（具体的な失敗シナリオを要求し、指摘は仮説として検証してから修正）

## 実績

- [[Yamasemi]]: 2026-07-08 レビュー初運用（task_events の INSERT ポリシー偽装可能性ほか4件が的中）→ 7/13 両輪開発体制（AGENTS.md 正本化・CI 新設）→ 7/15 夜間の v0.3 一斉実装で実装役（3並行 worktree・10ブランチ）。全体設計 v0.3 の作成も Codex 側
- [[swing-tradeシステム]]: 敵対的監査4ラウンドで誤採用を実弾前に阻止。①5桁コード切り詰めによる架空トレード（+146R）②v3 の+419万が実質2倍レバの数字 ③v4 ゲートの訂正データ二重計上 ④検証AF の候補検閲バグ（「指数超え」の崩落）。→ [[スイングトレード検証の掟]]
- その他: ブログのアイキャッチ画像生成、施主宅 Wi-Fi 検討のセカンドオピニオン（意図的に結論を突き合わせて分岐点を特定する使い方）

## Windows 運用の落とし穴（実測済み）

- npm グローバル版は古い。**デスクトップ版同梱の CLI を使う**（config.toml の CODEX_CLI_PATH が最新を指す）
- `codex exec` は stdin が開いたままだと無出力でハング → 必ず stdin を閉じる。出力は `--output-last-message <file>` で受ける
- Windows サンドボックスは時々 1312 エラーで全滅（特に並行3本時）→ 少し待って再投入
- 並行実行は git worktree で分離し、Codex には「git コマンド禁止・検証は lint/tsc/vitest/build のみ」を指示、コミット/push は Claude 側
