# Claude一般セッション 2026-06〜07

## 時期別の流れ

### 2026-06-19〜07-06: ymsk-core 立ち上げ（創業期）

- 6/18付の要件定義書を受領。課題「原価掌握の後手」の真因を freee→サクミルの手転記と特定し、freee を会計正本に残して他ツールを段階的に自作統合する4段階計画を確定（→ [[Yamasemi]]）
- 却下案も記録: 完全自作（過剰）、MCP連携で自作最小化（階層型見積を freee で表現できず）、Lovable/Bolt（階層データ・撤退可能性で不適）
- スタック確定: Next.js + Supabase（東京・RLS）+ Vercel + GitHub Private。最上位エンティティは estimates でなく **projects（案件）**（後段のタスク・写真・チャットが案件にぶら下がるため）
- 7/4 の転換点: 過去チャット横断分析（claude.ai エクスポート322会話含む）で「計画の生産量に対し実行者が本人一人」という問題の再定義 → 本人「着工」で実装フェーズ始動（→ [[AI協業開発体制]]）
- 7/5〜6: 見積システムを一気に構築・本番公開（ymsk-core.vercel.app）。E2E 25項目、RLS 無限再帰バグ修正、PDF/CSV、freee メモタグ紐付け第1弾
- 7/6〜8 の夜間マラソンで4段階全ての叩き台（発注書・タスク・施工管理・BIM取込）が揃う。多エージェントレビューで CSV 経由の認可バイパス等12件超の実バグを捕捉
- Google Sheets 的同時編集は見送り（保存方式の全面再設計に見合わない）→ 差分競合+プレゼンス表示で代替
