# 設計業務WBS(工務店・木造新築注文住宅)

## 0. 前提・適用範囲・分解基準

- 対象: 木造在来軸組・2階建て以下の新築注文住宅。2025年4月施行の改正建築基準法(4号特例縮小=新2号建築物として構造関係図書の提出対象)および建築物省エネ法(省エネ基準適合義務化)の適用後を前提とする。
- 範囲: 設計受託(重要事項説明)から、確認済証受領・設計図書の工事部門引渡しまで。
- 除外: 集客・土地探し等の営業行為、請負契約締結行為、積算・見積査定(見積用図書の発行までは本WBSに含む)、工事監理、施工段階の施工図、リフォーム(大規模の修繕・模様替)系フロー。リフォーム系は現況調査・既存不適格判定・確認申請要否分岐が入るため別WBSを要する。
- 原子タスクの停止基準(「これ以上分解できない」の定義): ①単一担当者に割当可能 ②1作業セッションで完了可能 ③完了判定が二値(done / not done)。3条件を満たした時点で分解を停止した。
- 凡例:
  - 【法:◯◯】 法令上の根拠がある法定業務
  - 【条件】 案件条件により発生
  - 【境界】 社内分掌により設計部門外となりうる(帰属判断は各社運用に依存)
- 根拠の性質: 法定業務には法令名を付記した。工程分解そのものは法定様式ではなく一般的な工務店実務の整理であり、網羅性を保証する一次ソースは存在しない。

## 1. 受託・与件確定

### 1.1 設計受託手続
- 1.1.1 設計業務の範囲(調査・基本設計・実施設計・申請代理・監理の別)を書面で定義する
- 1.1.2 重要事項説明書を作成する【法:建築士法24条の7】
- 1.1.3 管理建築士または所属建築士が重要事項説明を実施し、記録(交付日・説明者)を残す【法:建築士法24条の7】
- 1.1.4 設計受託契約を締結する(工事請負契約一体型の場合は契約書内の設計条項の記載を確認する)【境界】
- 1.1.5 確認申請等の代理者委任状を施主から取得する

### 1.2 要望ヒアリング
- 1.2.1 家族構成・年齢・将来の同居/独立予定を聴取する
- 1.2.2 現住居の不満点を聴取する
- 1.2.3 部屋数・広さ・こだわり要望をヒアリングシートに記録する
- 1.2.4 持込家具・家電の寸法リストを受領する
- 1.2.5 車・自転車の台数と車種(全長・回転半径)を確認する
- 1.2.6 ペット飼育の有無と仕様影響(床材・臭気)を確認する
- 1.2.7 生活時間帯・在宅勤務の有無を確認する
- 1.2.8 要望の優先順位(must / want)を施主と確定する

### 1.3 予算与件
- 1.3.1 総予算の内訳(建物本体・外構・諸費用・地盤改良予備費)を確認する
- 1.3.2 住宅ローン事前審査の状況を確認する【境界】
- 1.3.3 補助金・税制優遇の活用意向を確認する

## 2. 敷地・法規調査

### 2.1 机上調査(資料収集)
- 2.1.1 住宅地図・公図で敷地の地番・形状を特定する
- 2.1.2 土地の登記事項証明書を取得する
- 2.1.3 既存建物がある場合、建物の登記事項証明書を取得する【条件】
- 2.1.4 地積測量図・確定測量図の有無を法務局で確認する
- 2.1.5 都市計画情報で用途地域を確認する
- 2.1.6 建ぺい率・容積率の指定値を確認する
- 2.1.7 防火地域・準防火地域・法22条区域の別を確認する
- 2.1.8 高度地区・地区計画・建築協定の有無を確認する
- 2.1.9 景観計画区域・景観条例の該当を確認する
- 2.1.10 周知の埋蔵文化財包蔵地への該当を包蔵地図で確認する
- 2.1.11 洪水浸水想定区域をハザードマップで確認する
- 2.1.12 土砂災害警戒区域・特別警戒区域を確認する
- 2.1.13 液状化想定を確認する
- 2.1.14 上水道管路図(位置・口径)を取得する
- 2.1.15 下水道台帳(公共桝位置・管底高)を取得する
- 2.1.16 都市ガス供給エリアか確認する

### 2.2 役所調査(窓口・電話)
- 2.2.1 建築指導課で前面道路の種別(法42条の項号)を確認する
- 2.2.2 道路の認定幅員とセットバック要否を確認する
- 2.2.3 基準法上の道路に接していない場合、法43条2項の認定・許可の要否を確認する【条件】
- 2.2.4 役所に建ぺい率・容積率の指定値と角地緩和・防火緩和の適用可否を確認する
- 2.2.5 道路斜線・北側斜線・高度地区斜線の適用値を確認する
- 2.2.6 日影規制の対象・測定水平面を確認する
- 2.2.7 中間検査の指定有無・対象工程を特定行政庁に確認する【条件:法7条の3】
- 2.2.8 開発許可(都市計画法29条)・市街化調整区域の建築許可(同43条)の要否を確認する【条件】
- 2.2.9 農業委員会で農地転用(農地法4条/5条)の要否を確認する【条件】
- 2.2.10 盛土規制法の規制区域該当と許可・届出要否を確認する【条件】
- 2.2.11 下水道課で公共下水接続か浄化槽区域かを確認する
- 2.2.12 浄化槽区域の場合、放流先と設置に関する市町村基準を確認する【条件】
- 2.2.13 水道局で加入金・引込口径・分岐条件を確認する
- 2.2.14 教育委員会で文化財保護法93条届出の要否を確認する【条件】
- 2.2.15 地区計画区域内の行為届出(都市計画法58条の2・着手30日前)の要否を確認する【条件】

### 2.3 現地調査
- 2.3.1 境界標の有無・位置を全点確認し写真記録する
- 2.3.2 敷地の間口・奥行を実測する
- 2.3.3 敷地と道路・隣地の高低差をレベルで測定する
- 2.3.4 前面道路の幅員を実測する
- 2.3.5 側溝・縁石・歩道切下げの位置を記録する
- 2.3.6 電柱・支線・街灯の位置を記録する
- 2.3.7 上水道量水器の位置・口径を確認する
- 2.3.8 下水公共桝の位置・深さを実測する
- 2.3.9 雨水の排水先(側溝/浸透)を確認する
- 2.3.10 都市ガス引込管の位置を確認する【条件】
- 2.3.11 越境物(枝・擁壁・配管・屋根)の有無を確認する
- 2.3.12 隣地建物の窓・給湯器・エアコン室外機の位置を記録する
- 2.3.13 方位と時刻別の日照条件を確認する
- 2.3.14 敷地全周と道路からの見えがかりを写真撮影する
- 2.3.15 テレビ・携帯の電波受信状況を確認する
- 2.3.16 工事車両の進入経路と支障電線の高さを確認する【境界】

### 2.4 測量・地盤
- 2.4.1 現況測量の要否(高低差・不整形・境界不明時)を判断する
- 2.4.2 現況測量を土地家屋調査士へ外注する【条件】
- 2.4.3 測量成果(現況図)を受領し敷地面積・高低を照査する
- 2.4.4 地盤調査(SWS試験)を調査会社へ発注する
- 2.4.5 調査ポイント(建物四隅+中央)を配置図で指示する
- 2.4.6 地盤調査報告書を受領する
- 2.4.7 地盤判定(改良要否・推奨工法・概算費用)を確認する
- 2.4.8 改良必要時、工法提案書を照査し採用工法を決定する【条件】
- 2.4.9 近隣の既往地盤データ・旧地形図を参照する

### 2.5 与件確定
- 2.5.1 法規制一覧表(項目・規制値・根拠・確認先)を作成する
- 2.5.2 敷地調査報告書を作成する
- 2.5.3 設計与件書(要望×法規×予算×地盤)を確定し施主承認を得る

## 3. 企画・基本計画

### 3.1 ボリューム・配置検討
- 3.1.1 建ぺい率・容積率上限から計画面積レンジを算定する
- 3.1.2 斜線・高さ制限の断面チェックを行う
- 3.1.3 配置案(建物・駐車・アプローチ・庭・物置)を複数作成する
- 3.1.4 駐車の転回・進入軌跡を検証する

### 3.2 性能・仕様方針
- 3.2.1 断熱等級・UA値の目標値を設定する
- 3.2.2 気密(C値)の目標値を設定する
- 3.2.3 耐震等級の目標と計算ルート(壁量等/性能表示/許容応力度)を決める
- 3.2.4 換気方式(第1種/第3種)の方針を決める
- 3.2.5 冷暖房計画(台数・設置方式)の方針を決める
- 3.2.6 太陽光・蓄電池の搭載方針を決める
- 3.2.7 省令準耐火構造の採用可否を決める【条件】
- 3.2.8 長期優良住宅認定の取得可否を判断する
- 3.2.9 適用補助金の公募要領(要件・予算枠・期限)を確認する ※年度事業のため公募要領が一次ソース
- 3.2.10 認定・補助金の申請期限を設計工程表に反映する

## 4. 基本設計

### 4.1 プランニング
- 4.1.1 ゾーニング図を作成する
- 4.1.2 平面プラン(1F)初案を作成する
- 4.1.3 平面プラン(2F)初案を作成する
- 4.1.4 家事動線・回遊動線をチェックする
- 4.1.5 収納量を現住居比でチェックする
- 4.1.6 柱・壁の直下率を仮チェックする
- 4.1.7 耐力壁ラインの成立性を仮チェックする
- 4.1.8 屋根伏(形状・勾配・太陽光設置面)を検討する
- 4.1.9 立面4面の初案を作成する
- 4.1.10 配置図(境界後退距離・設計GL含む)を作成する
- 4.1.11 面積表(建築面積・延床面積・法規上の床面積)を作成する
- 4.1.12 外観・内観パースを作成する

### 4.2 概算
- 4.2.1 概算見積(社内係数モデル)を算出する
- 4.2.2 概算と予算の差額を把握し、調整候補(減額項目)を列挙する

### 4.3 施主合意(反復)
- 4.3.1 プレゼン資料を作成する
- 4.3.2 打合せを実施し議事録を作成する
- 4.3.3 修正要望を図面へ反映する
- 4.3.4 基本設計図書に施主承認(記名)を取得する

### 4.4 基本設計時性能検討
- 4.4.1 概算外皮計算(UA)を行う
- 4.4.2 日射取得・遮蔽(庇の出・窓面積比)を検討する
- 4.4.3 窓種・ガラス仕様の割付方針を決める

## 6. 申請・認定

### 6.1 建築確認申請【法:基準法6条】
- 6.1.1 提出先(指定確認検査機関/建築主事)を決める
- 6.1.2 必要に応じて事前相談を行う【条件】
- 6.1.3 確認申請書(第一面〜第六面)を作成する
- 6.1.4 建築計画概要書を作成する
- 6.1.5 建築工事届を作成する【法:基準法15条】
- 6.1.6 委任状を添付する
- 6.1.7 意匠系添付図書(付近見取図・配置図・平面・立面・断面・仕上表)を整える
- 6.1.8 新2号建築物の構造関係図書(伏図・壁量計算等)を整える【法:2025年4月施行改正基準法】
- 6.1.9 省エネ関係図書(仕様基準適合表または計算書)を整える【法:建築物省エネ法】
- 6.1.10 シックハウス関係図書(換気計算書・使用建材の等級)を添付する【法:基準法28条の2】

## 7. 着工前引継

- 7.1 実施設計図書一式を製本・PDF化して発行する
- 7.2 見積用図面一式を積算担当へ引き渡す【境界】
- 7.3 プレカット工場へ構造図・伏図・仕様を送付する
- 7.4 プレカット図(土台・床・小屋)を照査する
- 7.5 プレカット図の指摘を返送し再図を確認する
- 7.6 プレカット図を最終承認する
- 7.7 サッシ・玄関ドアの発注仕様書(品番・色・ガラス)を確定する【境界:発注行為は工務部の場合あり】
- 7.8 住宅瑕疵担保責任保険の設計施工基準(基礎・防水仕様)との適合を確認する【境界:申込・現場検査は工事部門】

- 7.10 建物配置・設計GL・ベンチマークを現地で監督と確定する
- 7.11 地縄確認に立ち会い施主承認を得る
- 7.12 着工後に残る設計タスク(電気最終・外構詳細等)を引継書に明記する

## 補足(分解の限界)

- 【境界】タスクの帰属(設計/営業/工事)は社内分掌に依存し、本WBS単独では確定できない。
- 実務系タスク(図面作成手順の内部工程、例: 「壁芯を入力する」等)はさらに分解可能だが、停止基準①〜③を満たすため本WBSでは打ち切った。CADオペレーション粒度まで要する場合は基準の再定義が必要。
- リフォーム(大規模の修繕・模様替)・平屋200㎡超・3階建て・混構造は前提外。分岐条件が異なるため別WBSを要する。
