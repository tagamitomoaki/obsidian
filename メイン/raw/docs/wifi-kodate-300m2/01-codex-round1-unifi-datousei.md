# 結論

ChatGPTによるUniFi推奨は、製品としては適切です。しかし、一般施主が自力保守する前提では、条件付きで過剰です。

特に問題なのは、次の2点です。

1. 延床300㎡を「各階U6+ 1台、合計2台」で十分と判断すること  
2. VLAN、防犯カメラ、ゲストWi-Fi、広告ブロックまで含めた業務用寄りの構成を、保守体制なしで引き渡すこと

300㎡・2階建てでは、設計上は各階2台、合計4台分の天井配線を用意すべきです。実際の設置台数は3～4台を基準とし、竣工後の実測で決定します。

私の最終推奨は次のとおりです。

- 施主または工務店にUniFiを保守できる担当者がいる  
  → UniFi、AP 4台構成
- 保守担当者がいない  
  → TP-Link Decoを3～4台、有線バックホールで使用
- 工務店が複数棟を継続管理する  
  → UniFiまたはOmadaを工務店の標準仕様として運用
- NEC/Buffalo  
  → 国内ISPとの接続や交換の容易さを最優先する場合。ただし300㎡では家庭用メッシュ機を無線中継で置くだけでは不足しやすい

製品より重要なのは、新築時にCAT6A、天井AP用配線、空配管、情報ラックを施工しておくことです。ここを省略すると、後から製品を替えても根本的には改善できません。

# 1. 300㎡にU6+ 2台は妥当か

## 面積だけでは判定できない

無線LANの到達範囲は、延床面積だけでは決まりません。

影響が大きい要素は次のとおりです。

- 1フロアの平面形状
- APから各部屋までの距離
- 鉄骨、RC壁、制震壁、構造用面材
- 床暖房の金属層
- 金属サイディング、Low-E複層ガラス
- 浴室、キッチン収納、冷蔵庫などの遮蔽物
- 2.4GHz、5GHz、6GHzのどこまでをカバー対象にするか
- 屋外、ガレージ、庭、防犯カメラまで対象にするか
- 各部屋で必要な最低通信速度

特にWi-Fi 6E/7の6GHz帯は、5GHzより壁や床を越えにくいため、「Wi-Fi 7にしたから台数を減らせる」とは限りません。逆にAPの配置密度が必要になる場合があります。

## U6+ 2台に対する判断

各階約150㎡と仮定すると、各階1台だけでは次の問題が予想されます。

- 平面の端部や水回りを挟んだ部屋で5GHzが弱くなる
- 6GHzはさらに利用可能範囲が狭い
- AP故障時に片方の階が実質的に無線不通になる
- APの送信は届いても、スマートフォン側の弱い送信がAPまで戻らない
- 高速通信ではなく「辛うじて接続できる範囲」になりやすい

したがって、U6+ 2台は「接続できる可能性はあるが、新築時の確定仕様として採用するには危険」という評価です。

建物中央に吹抜けがあり、間仕切りが少なく、木造で、5GHzの端部速度を要求しないなら2台で届く可能性はあります。しかし、図面、壁材、天井高、電波実測がないため、十分とは断定できません。

## 推奨台数

標準案は次のとおりです。

- 1階：2台
- 2階：2台
- 合計：4台

ただし、最初から4台すべてを稼働させる必要はありません。

- 天井配線と取付位置は4～6か所用意
- 当初3台で運用
- 竣工後に電波測定
- 不足箇所があれば4台目を追加

この方法が合理的です。

APを増やせば自動的によくなるわけでもありません。同一チャネル干渉を防ぐため、送信出力、チャネル幅、チャネル割当を調整する必要があります。

- UDM-SE中心の一体型構成
- Cloud Gateway Fiber＋PoEスイッチ＋必要に応じてNVR

- UniFiネットワーク機器：15万～25万円程度
- ラック、UPS、パッチパネル、ケーブル部材：5万～15万円程度

工務店が設定まで請け負うなら、「箱代」だけを施主に説明してはいけません。VLAN設計、回線開通対応、設定保存、障害対応手順まで含めた工数が必要です。

# 3. 1G回線と10G回線の注意点

10G契約をしても、家庭内の全端末で10Gbpsが出るわけではありません。

経路全体が対応している必要があります。

```text
ONU/HGW
  ↓ 10GbE
ゲートウェイ
  ↓ 10GbE
基幹スイッチ
  ↓ 2.5GbE
AP
  ↓ 無線
Wi-Fi 7端末
```

どこかに1GbE機器があれば、その経路は概ね1Gbps以下になります。

また、UniFiゲートウェイのIDS/IPS有効時性能は製品によって異なります。

- Cloud Gateway Ultra：1Gbps
- Cloud Gateway Max：2.3Gbps
- UDM-SE：3.5Gbps
- Cloud Gateway Fiber：5Gbps

これらはUbiquitiの公称値です。[Ubiquiti Cloud Gateway製品比較](https://www.ui.com/jp/ja/cloud-gateways)

10Gインターネットを契約するだけでUDM-SEを採用すると、「WANポートは10Gだが、セキュリティ機能有効時に10Gを処理する構成ではない」という不一致が生じます。

一般住宅なら、次の設計が費用対効果に合います。

- インターネット：1Gまたは10G
- 基幹リンク：10G対応
- APと主要端末：2.5G
- テレビ、IoT、一般端末：1G

## フレッツ系IPoE

2026年7月時点のUbiquiti公式資料では、IPv6、DS-Liteに加え、日本向けのv6プラスおよびOCNバーチャルコネクトのMAP-Eをサポートすると記載されています。[Ubiquiti「Configuring IPv6 in UniFi」](https://help.ui.com/hc/en-us/articles/36378535649687-Configuring-IPv6-in-UniFi)

ただし、次は契約前に実機確認が必要です。

- ISP名
- IPv4 over IPv6方式
- v6プラス、OCNバーチャルコネクト、transix、クロスパス等の別
- ひかり電話の有無
- HGWを残すか
- 固定IP契約の有無
- 使用予定のUniFi OS／Networkバージョン

公式資料上の対応と、個別ISPの自動設定が正常に動作することは同義ではありません。Ubiquiti公式コミュニティには、特定バージョンとtransixのDS-Liteについて不具合報告があります。これは利用者報告であり、すべての環境で発生することを意味しません。[UniFi OS 5.1.12のコミュニティ報告](https://community.ui.com/releases/41549e59-0a2f-4ee9-8450-dee7ec15a58d?replyId=cd2b5b91-e39c-4e64-81a1-923a8cbb7613)

保守を簡単にするなら、NTTまたはISPのHGWを回線終端ルーターとして残し、UniFiをその配下で使う設計もあります。ただし、二重ルーター、ポート開放、VPN、IPv6、VLAN境界が複雑になるため、構成図が必要です。

# 4. Ubiquitiのメリットとデメリット

## メリット

### 統合管理

AP、スイッチ、ゲートウェイ、カメラ、ドアベルを同じ管理画面で確認できます。

- 接続端末
- 電波状態
- APごとの負荷
- PoE給電状態
- VLAN
- ゲストネットワーク
- ファームウェア
- カメラ映像

複数機器を個別アプリで管理するより、障害箇所を追いやすくなります。

### 有線AP構成に適している

新築住宅で天井にPoE配線し、有線バックホールでAPを配置する用途に合っています。

### ライセンス料なしで遠隔管理可能

UniFiの制御機能はCloud Gateway等のローカル機器で動作します。インターネット停止中もローカル管理できます。[Ubiquitiのクラウド構成説明](https://help.ui.com/hc/en-us/articles/30319146145175-Understanding-UniFi-Cloud-Architecture)

UIアカウントは必須ではなく、ローカル専用アカウントでも運用可能です。ただし、遠隔管理、自動バックアップ、通知などにはUIアカウントが実質必要です。[UniFi Local Management](https://help.ui.com/hc/en-us/articles/28457353760919-UniFi-Local-Management)

### VLANやSSID分離が容易

例えば次の分離ができます。

- 家族用
- 来客用
- IoT用
- 防犯カメラ用
- 工務店保守用

ただし、分離ルールを理解せず設定すると、AirPlay、Chromecast、プリンター、スマートホーム機器の検出が動かなくなることがあります。

## デメリット

### 一般家庭用ルーターより設定項目が多い

初期設定後に通常利用するだけなら、施主が毎日操作する必要はありません。しかし、次の障害対応にはネットワーク知識が必要です。

- VLAN間通信
- DHCP
- DNS
- IPv6
- MAP-E／DS-Lite
- PoE
- チャネル干渉
- ファームウェア更新後の不具合
- カメラ録画領域
- UIアカウントと所有権移転

「アプリで設定できる」ことと「一般人が障害原因を切り分けられる」ことは別です。

### 国内の交換体制は購入経路に依存する

Ubiquiti日本公式ストアは存在します。国内には網屋、ソネット等、Ubiquitiを扱う正規販売経路もあります。[網屋](https://www.amiya.co.jp/ubiquiti/news/)、[ソネットのサポート説明](https://sonet.co.jp/support)

保証や先出し交換の条件は、購入先と保守契約によって異なります。ソネットは同社経由販売品に2年間のハードウェア保証を付与すると説明していますが、これは他店購入品の条件ではありません。

施工者がAmazon、海外通販、国内公式ストア、代理店仕入れを混在させると、故障時の窓口が分散します。

### 技適は型番単位で確認が必要

日本国内で無線機器を使用するなら、技術基準適合証明等を受けた国内向け型番を使用すべきです。

「U7シリーズだから全部使用できる」「海外版でも同じハードウェアだからよい」という判断は不可です。

確認方法は次のいずれかです。

- 日本公式ストアで国内向けとして販売されている型番を購入
- 本体表示または電子表示の技適マークと番号を確認
- 総務省の電波利用ホームページで型番・認証番号を確認
- 正規代理店に国内利用可否を文書で確認

APを海外から個人輸入する構成は、工務店の標準仕様にすべきではありません。

### 故障時に家全体が影響を受ける

統合構成では、ゲートウェイやPoEスイッチが単一障害点になります。

- ゲートウェイ故障：インターネット停止
- PoEスイッチ故障：全APとカメラが停止
- HDD故障：録画停止
- UIアカウント喪失：遠隔管理や所有権移転が困難

予備の家庭用ルーター、設定バックアップ、交換手順が必要です。

## NEC Aterm／Buffalo

### 適する条件

- 施主が自分で交換したい
- 国内ISPとの接続設定を簡単にしたい
- VLANやカメラ統合が不要
- 家電量販店で代替機を入手したい

### 問題点

- 複数APの一元的な電波設計・監視はUniFiより弱い
- VLANやSSID間の詳細制御には不向き
- 家庭用機器を棚や床に置くと、配置自由度が低い
- 無線バックホールでは速度と安定性が落ちやすい

採用する場合でも、各階をCAT6Aで接続し、有線バックホールにすべきです。

## TP-Link Deco

一般施主向けの現実的な代替案です。

Deco BE65は2.5GbEポートを4個搭載し、有線バックホールに対応しています。メーカー発表時の想定販売価格は1台37,180円、2台67,980円でした。[TP-Linkの製品発表](https://www.tp-link.com/jp/press/news/21111/)

### メリット

- アプリ中心で設定できる
- 有線バックホール対応
- Wi-Fi 7対応
- 主要な国内IPv6 IPoE方式への対応をメーカーが明示
- 交換時の再設定が比較的容易
- 300㎡なら3～4台構成を取りやすい

### デメリット

- 本格的なVLAN設計には向かない
- 天井埋込み型APほど設置がすっきりしない
- AC電源が各設置場所に必要
- 高度なセキュリティや保護者機能に有料サービスを含む場合がある
- APモードやIPv6 IPoE利用時に一部HomeShield機能が使えないとメーカーが注記している

「施主が自分で保守する」という条件では、UniFiよりDecoの方が現実的です。

## TP-Link Omada

OmadaはUniFiに近い業務用管理方式です。

- ゲートウェイ
- PoEスイッチ
- 天井AP
- コントローラー
- VLAN
- クラウド管理

を統合できます。

例えばEAP773はWi-Fi 7 AP、SG2210XMP-M2は2.5GbE PoE＋10G SFP+対応スイッチです。後者は日本公式ページ上で「発売予定」と表示されているため、国内調達可否を発注時に確認する必要があります。[SG2210XMP-M2公式ページ](https://www.tp-link.com/jp/business-networking/smart-switch/sg2210xmp-m2/)

### UniFiとの比較

- 機器価格は抑えられる場合がある
- 国内TP-Link窓口を利用しやすい
- 設定難度は家庭用Decoより高い
- 一般施主が自力保守する点ではUniFiと同じ問題が残る
- カメラ、ドアベルまで含む統合性ではUniFiが優位

Omadaは「安いUniFi」と考えるべきではありません。保守担当者が必要な点は同じです。

# 6. 新築時に必須とする配線・配管設計

ここは製品選定から独立して決めるべきです。

## 基本原則

すべてのLAN配線を情報ラックへスター配線します。

```text
各部屋・AP・カメラ
        │
        │ CAT6A個別配線
        ↓
情報ラック／パッチパネル
        ↓
スイッチ
        ↓
ゲートウェイ
        ↓
ONU／HGW
```

部屋から部屋へ数珠つなぎにしてはいけません。

## CAT6Aを標準にする

新築なら、固定配線はCAT6Aを推奨します。

理由は次のとおりです。

- 10GBASE-Tを想定できる
- PoE、PoE+、PoE++に対応しやすい
- ケーブル交換が困難な天井・壁内に先行投資する価値がある
- 機器は後から交換できるが、壁内配線の交換は難しい

施工時にはケーブルカテゴリだけでなく、次も確認します。

- CAT6A対応ジャック
- CAT6A対応パッチパネル
- 曲げ半径
- 強電線との離隔
- 束ね過ぎによるPoE発熱
- 端末処理品質
- 各線のラベル
- 配線試験結果

「CAT6Aケーブルを使ったが、ジャックはCAT5e」「試験していない」という施工では意味が減ります。

## 推奨配線数

間取りが提示されていないため、総本数は確定できません。設計原則は次のとおりです。

### 天井AP

- 1階：2か所＋予備1か所
- 2階：2か所＋予備1か所
- 合計：最低4本、推奨6本

各場所へCAT6Aを1本、情報ラックから直接配線します。

予備位置は吹抜け、廊下中央、LDK反対側など、電波測定後に選択できる場所とします。

天井裏でケーブルを丸めて終わらせず、位置が分かるよう図面と写真を残します。

### 居室

- 各居室：最低2口
- 書斎：4～6口
- リビングテレビ周辺：4～6口
- AVラック：4～8口
- NAS・サーバー予定位置：2～4口
- プリンター位置：1～2口

PC、テレビ、ゲーム機、レコーダー、NASは可能な限り有線化します。これによりWi-Fiの混雑を減らせます。

### 防犯設備

- 屋外カメラ候補位置：各1本
- インターホン／ドアベル：1～2本
- 門柱：LAN＋空配管
- ガレージ：AP用とカメラ用を分ける
- 宅配ボックス、スマートロック制御盤：必要に応じてLAN

カメラとAPを1本のケーブルで兼用しない設計にします。

## 空配管

最低限、次の空配管を設けます。

- 引込点から情報ラック
- 情報ラックから各階の天井裏
- 情報ラックから書斎
- 情報ラックからテレビ・AV位置
- 情報ラックから門柱
- 情報ラックからガレージ
- 情報ラックから屋根裏
- 将来の屋外AP位置

配管径は、将来CAT6Aを複数本または光ファイバーを通せる余裕を持たせます。細いCD管を長距離・急曲げで施工すると、実質的に再利用できません。

配管には呼び線を残し、両端を識別します。

## 光ファイバー用経路

母屋と離れ、ガレージ、別棟、門柱間は、銅線LANだけでなく光ファイバーを通せる空配管を確保します。

屋外建物間の銅線LANは、雷サージや接地電位差の経路になり得ます。別棟間は光接続を優先します。

## 情報分電盤ではなく情報ラック

一般的な住宅用情報分電盤は、次の点で不足しやすいです。

- 奥行き不足
- 放熱不足
- 16ポートPoEスイッチが入らない
- UDM-SE等の19インチ機器が入らない
- 配線の曲げ半径を確保できない
- UPSが置けない

推奨は壁掛けまたは据置きの19インチラックです。

必要条件は次のとおりです。

- 奥行き450～600mm程度を機器仕様に合わせて確保
- 前後または上下の換気
- 専用100Vコンセント
- UPS用スペース
- ONU／HGW設置スペース
- パッチパネル
- ケーブルマネージャー
- 接地
- 交換作業用の前面空間
- 夏季温度が上がり過ぎない場所

寝室や静かな書斎に置く場合、PoEスイッチのファン音とUPS音を確認します。

## 電源

次の場所に電源を用意します。

- ONU／HGW
- ゲートウェイ
- PoEスイッチ
- NVR／NAS
- UPS
- Deco等を使う可能性があるAP候補位置
- 作業用予備コンセント

PoE天井APだけを前提にすると、将来家庭用メッシュ機へ変更した際にAC電源がなく困ります。天井AP候補位置の近くに、隠せるAC電源または電源を追加できる空配管を用意すると選択肢が残ります。

## 引渡し資料

工務店は次を引き渡すべきです。

- 論理構成図
- 配線系統図
- 各LAN口の番号
- パッチパネルとの対応表
- 壁を閉じる前の配線写真
- ケーブル試験結果
- 機器型番とシリアル番号
- 購入先と保証期限
- 設定バックアップ
- UIアカウントの所有者
- VLAN・SSID一覧
- 管理者情報の引渡し手順
- 障害時の切り分け手順
- 初期化してはいけない機器の説明

パスワードを平文で竣工図書に印刷する方法は避け、施主所有のパスワード管理手段に移管します。

# 7. 保守主体別の最終推奨

## 施主が一般利用者で、工務店もネットワーク保守をしない場合

推奨構成：

- ISPまたはNTTのHGW
- TP-Link Deco Wi-Fi 7対応機 ×3～4
- 全台CAT6Aによる有線バックホール
- 一般端末用SSID
- ゲストSSID
- 必要ならIoT用SSID
- 市販の2.5GbEスイッチ
- 防犯カメラはカメラメーカーの専用NVR

この構成ではVLANによる厳密な隔離は捨て、復旧の容易さを優先します。

故障時はDecoを1台交換し、アプリから再登録する運用にできます。

## 施主がIT機器を扱える場合

推奨構成：

- Cloud Gateway Fiber
- Pro Max 16 PoE
- U7 LiteまたはU7 Pro ×4
- CAT6A
- 10G基幹リンク
- UPS
- VLANは最大3～4個
- カメラは必要に応じてUniFi Protect

VLANを細分化し過ぎるべきではありません。

実用上は次の4個で足ります。

1. Trusted：PC、スマートフォン、NAS
2. IoT：家電、スマートスピーカー
3. Security：カメラ、ドアベル
4. Guest：来客

mDNS、AirPlay、Chromecast、プリンター通信について、必要な通信だけを明文化します。

## 工務店が継続保守する場合

UniFiを採用できます。ただし、製品を取り付けるだけでは保守サービスになりません。

必要なのは次です。

- 工務店所有ではなく施主所有のUIアカウントをOwnerにする
- 工務店は別の管理者アカウントとして招待する
- 多要素認証を有効化する
- 自動バックアップを有効化する
- ファームウェアの自動更新範囲を決める
- 障害時連絡先と対応時間を契約化する
- 交換用ゲートウェイまたは簡易ルーターを用意する
- APを1台停止しても最低限通信できる配置にする
- 竣工時と変更後に設定を保存する

UIアカウントのOwnerを施工会社にすると、会社廃業、担当者退職、契約終了時に所有権問題が発生します。Ubiquitiは所有権移転機能を案内していますが、最初から施主所有にする方が安全です。[UniFiの所有権移転説明](https://help.ui.com/hc/en-us/articles/14275946860311-UniFi-Password-Recovery-and-Ownership-Transfer)

# 8. 工務店が施主に説明すべき論点

説明は「どのメーカーが高性能か」ではなく、次の順序で行うべきです。

1. 必要なのは全館で接続できることか、全館で高速通信できることか
2. 庭、ガレージ、屋外カメラを対象にするか
3. NASや10G対応PCを使うか
4. Wi-Fi 7の6GHz帯をどこまで求めるか
5. 防犯カメラと住宅LANを統合するか
6. VLAN隔離が本当に必要か
7. 誰がファームウェア更新と故障対応を行うか
8. 故障時に何時間または何日停止してよいか
9. 施主は設定変更を自分で行うのか
10. 工務店の保守は有償か、引渡し後は免責か

施主には、次の説明が必要です。

> UniFiは家庭用ルーターより高性能というより、複数のネットワーク機器を統合管理するための製品です。  
> その代わり、故障時や設定変更時には管理者が必要です。  
> 管理者を置かない場合は、機能を減らして家庭用メッシュを有線接続する方が復旧しやすくなります。

# 最終判断

- 300㎡住宅にUniFiを使うこと自体は過剰ではない
- UDM-SEまで含むフルUniFi構成は、カメラ統合と保守担当者がいる場合に適切
- ネットワーク用途だけならUDM-SEは必須ではない
- U6+ 2台だけで300㎡を確実にカバーする設計は採用すべきでない
- APは3～4台、配線は4～6か所用意する
- Wi-Fi 7では高級APを少数置くより、必要位置に適切な台数を置く
- 一般施主の自力保守を優先するなら、有線バックホールのDecoが現実的
- 工務店が保守標準を構築するならUniFiが有力
- 最優先投資はCAT6A、スター配線、空配管、情報ラック、電源、竣工資料

したがって、この案件のベスト構成は一つではありません。

保守担当者が確保できるなら、**Cloud Gateway Fiber＋Pro Max 16 PoE＋U7 Lite／U7 Pro 4台**。

保守担当者が確保できないなら、**国内ISP対応ルーターまたはHGW＋Deco 3～4台の有線バックホール**。

この分岐を決めずに「高性能だからUniFi」と提案するのは設計ではなく、製品選定にとどまります。
