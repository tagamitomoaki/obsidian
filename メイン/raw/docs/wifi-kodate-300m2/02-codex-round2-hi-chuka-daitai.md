# 結論

今回の条件では、「中華製を除外」の意味を先に確定しない限り、製品選定は成立しません。

実務上は次の二つを分ける必要があります。

1. **中国企業・中国ブランドを採用しない**
2. **中国で製造された機器・部品を採用しない**

前者なら、TP-Linkを外し、Ubiquiti、HPE、NETGEAR、NEC、Buffalo、Yamahaを候補にできます。

後者なら、ブランド名だけでは判定できません。米国・日本ブランドでも、中国、台湾、ベトナム等のEMSで製造され、同一型番でも製造ロットにより原産国が変わる可能性があります。納入時に現物ラベル、梱包箱、インボイス、メーカーまたは代理店の原産国証明を確認する調達条件が必要です。

以下では、まず現実的な「中国企業・中国ブランドを除外」として比較します。

---

# 1. 「中華製は嫌」の整理

## ブランド国籍と製造国は別問題

| ブランド | 企業・ブランドの帰属 | 実務上の扱い |
|---|---|---|
| TP-Link | 中国系 | 今回は除外 |
| Ubiquiti | 米国企業 | 非中国ブランド。ただし全製品の非中国製造を保証するものではない |
| HPE Networking / Aruba | 米国企業 | 同上 |
| NETGEAR | 米国企業 | 同上 |
| NEC Aterm | 日本企業・日本ブランド | 設計・品質管理主体は日本。ただし日本製造とは限らない |
| Buffalo | 日本企業・日本ブランド | 同上 |
| Yamaha | 日本企業・日本ブランド | 同上 |

「米国ブランドなら中国製造ではない」「日本ブランドなら日本製」という説明はできません。

Ubiquitiについても、米国税関の原産国判定事例では、部品調達地、基板実装、ソフトウェア書込み、最終組立などの工程を基に原産国を判断しています。単純に本社所在地や組立地だけで決まりません。[米国税関のUbiquiti製品に関する原産国判断](https://www.customsmobile.com/rulings/docview?doc_id=HQ+H337456&highlight=one-day-2024)

## 施主に確認すべき質問

次のように確認するのが妥当です。

> TP-Link、Huawei、ZTEなど、中国企業が支配するブランドを除外するという意味ですか。それとも、米国・日本ブランドであっても中国工場で製造された機器を除外するという意味ですか。

後者なら、さらに次を仕様書に入れます。

- 納入時点の完成品原産国を中国以外とする
- 型番だけでなく製造ロット単位で確認する
- 梱包箱および本体ラベルの原産国表示を写真保存する
- 代理店に原産国証明または非中国原産の回答書を求める
- 交換品についても同じ条件を適用する
- 内部部品まで中国由来を禁止するのか、完成品原産国だけを見るのか定義する

内部部品まで中国由来を禁止すると、SoC、無線モジュール、電源、受動部品まで追跡する必要があり、一般住宅の工事仕様としては現実性が低くなります。

したがって推奨する定義は、次のいずれかです。

- **標準条件：中国企業・中国ブランドを除外**
- **厳格条件：完成品原産国が中国でないことを納品ロット単位で確認**

# 2. 保守担当者がいない場合の代替案

## NEC Aterm

### 構成可能性

Atermのメッシュ対応機は、有線バックホールに対応しています。メーカー資料上は、メッシュ中継機を最大9台接続できるため、親機1台＋中継機2～3台の構成自体は可能です。[Atermのメッシュ機能説明](https://www.aterm.jp/product/atermstation/special/mesh-wifi/)

ただし、メーカーの接続確認情報には、組み合わせによって「有線接続で利用すると通信が不安定になる場合がある」との注記があります。機種混在時の制約や、表示上の不整合も存在します。[Atermメッシュ接続確認情報](https://www.aterm.jp/support/connect/mesh/index.html)

### 評価

- 300㎡で3～4台：構成上は可能
- 有線バックホール：対応
- 設定難度：家庭用としては低い
- 遠隔一括管理：弱い
- VLAN・SSID分離・RF管理：業務用APより限定的
- 天井設置：基本的に不向き
- PoE給電：不可
- 設置形態：棚、造作収納、壁面付近
- 将来交換：家電量販店で調達しやすい

特に問題になるのは天井設置です。Atermは据置型で、ACアダプターと電源コンセントが必要です。天井裏に隠すと電波、放熱、保守性が悪化します。新築住宅の「天井AP前提」の設計とは噛み合いません。

また、複数台を置けることと、業務用APのようにチャネル、送信出力、ローミングを一元管理できることは同義ではありません。

### 概算

WX5400T6は2026年のセール例で1台約20,550円、2台セット約39,040円でした。[ケータイ Watchの実売確認例](https://k-tai.watch.impress.co.jp/docs/news/sale/2089796.html)

- 3台：約6万～7万円
- 4台：約8万～10万円
- スイッチ、情報ラック、配線工事：別
- 各設置場所にAC100Vが必要

家庭用としては成立しますが、工務店の高品質標準仕様としては第二候補です。

## Buffalo EasyMesh

### 構成可能性

BuffaloのEasyMesh対応ルーターは有線バックホールに対応しています。メーカー資料では、Buffalo製ルーターをコントローラーとした場合、エージェントは4台まで接続可能とされています。[Buffalo製品資料](https://www.buffalo.jp/product/detail/vol234.pdf)

コントローラーと各エージェントを有線接続する構成も可能です。エージェント側ではLAN端子または対応するINTERNET端子をバックホールに使えます。[有線接続端子の説明](https://www.buffalo.jp/support/faq/detail/124158144.html)

したがって、親機1台＋エージェント2～3台、合計3～4台は構成できます。

### 評価

- 300㎡で3～4台：構成可能
- 有線バックホール：対応
- 設定難度：比較的低い
- 遠隔管理・障害解析：限定的
- 天井設置：不向き
- PoE給電：不可
- 設置形態：据置または製品が許容する壁面設置
- メーカーを統一した方がトラブルを減らせる
- エージェントごとの電源コンセントが必要

WSR-5400XE6は2026年7月時点で税込約16,800～20,000円の販売例があります。[2026年6月の販売資料](https://www.takagi-c.com/dcms_media/other/takagi-pc-tushin_2606.pdf)、[ノジマオンライン](https://online.nojima.co.jp/commodity/1/4981254064634/)

### 概算

- WSR-5400XE6×3：約5万～6万円
- 同×4：約7万～8万円
- より上位のWi-Fi 7機を使う場合：約10万～20万円
- 配線・ラック・スイッチ：別

Atermと同様、安価で施主自身が交換しやすい点が利点です。一方、4台を各部屋の棚に配置するため、天井APより電波設計の再現性が低く、家具や家電の影響を受けます。

Atermとの比較では決定的な品質差はありません。工務店が設定手順・交換手順を標準化しやすい方を選ぶべきです。

## NETGEAR Orbi

### 実力

Orbi 770は、3台セット、Wi-Fi 7、2.5GbE有線バックホールに対応し、公称カバー範囲も300㎡を超えます。[NETGEAR Orbi 770公式仕様](https://www.netgear.com/jp/home/wifi/mesh/rbe773/)

家庭用メッシュとしてはAterm/Buffaloより次の点で上です。

- ルーターとサテライトが同一製品群として設計されている
- 有線・無線バックホールの両方を想定
- トライバンド
- アプリ中心で比較的簡単
- 2.5GbEバックホール
- 3台セットで構成が完結

ただし、問題があります。

- 日本公式ページ上でOrbi 770は「この地域では利用できません」と表示される
- 正規流通、在庫、国内保証の継続性が不透明
- 天井設置・PoEには非対応
- 縦長の据置筐体で設置場所を選ぶ
- Armorなど一部の追加セキュリティ機能は有料
- 高価格
- 正規販売店以外では国内保証上の問題がある

公式仕様では正規販売店購入時のハードウェア保証は1年です。[Orbi 770公式仕様](https://www.netgear.com/jp/home/wifi/mesh/rbe773/)

### 概算

日本の安定した正規流通価格を確認できないため、2026年の国内価格は未確定です。海外希望価格は3台で899.99ドルでしたが、為替、消費税、輸送、国内保証を考えると、日本での調達総額は概ね15万～25万円以上になる可能性があります。この金額は推計です。

価格に対して、工務店標準仕様としての国内保守性が弱いので推奨順位は低くなります。

## HPE Networking Instant On

旧来「Aruba Instant On」と呼ばれていた製品群です。

### 中間解になるか

なります。ただし、「保守担当者が完全に不要」という意味ではありません。

Instant Onは以下を備えます。

- 天井・壁面取付
- PoE給電
- 複数APの一元管理
- 有線バックホール
- SSID、ゲスト、VLANの管理
- アプリまたはWebポータルによるクラウド管理
- ライセンス料金不要
- 障害時のAP交換機能
- 業務用APとしての電波・ローミング設計

HPEはInstant On管理アプリを無料と明記しています。[HPE Instant On公式説明](https://instant-on.hpe.com/ja/industries/smart-workspaces/)

AP22は2×2のWi-Fi 6、AP25は4×4のWi-Fi 6です。AP25は802.3at給電が必要です。[HPE Instant On 2025年カタログ](https://www.hpe.com/psnow/downloadDoc/HPE%20Networking%20Instant%20On%E8%A3%BD%E5%93%81%E3%82%AB%E3%82%BF%E3%83%AD%E3%82%B02025%E5%B9%B4Vol.1-a00143461jpn.pdf?deepLink=&form=false&hf=regular&id=a00143461jpn&isFutureVersion=true&originalObjectName=&prelaunchSection=&preview=false&print=&r=&section=&softrollSection=&ver=4)

300㎡の戸建てなら、通常はAP22または同クラスを4台で十分です。AP25を4台使う必然性は、高密度利用、大量の同時通信、NASへの高速アクセスなどがなければ低いです。

### UniFiとの違い

| 項目 | Instant On | UniFi |
|---|---|---|
| 初期設定 | 比較的簡単 | 選択肢が多く複雑 |
| 管理 | クラウド前提 | ローカル管理とクラウド連携 |
| 機能の深さ | 必要十分 | 詳細設定が多い |
| ゲートウェイ統合 | 選択肢が限定的 | 強い |
| AP・スイッチ統合 | 対応 | 対応 |
| カメラ等の統合 | 弱い | 強い |
| ライセンス | 無料 | 基本無料 |
| 施主による管理 | Instant Onの方が容易 | 管理画面の理解が必要 |
| 施工業者の遠隔保守 | 可能 | より詳細に可能 |

「UniFiより簡単で業務品質」という評価は妥当です。

ただし、クラウドアカウントの所有者を工務店にしてはいけません。施主を所有者とし、施工業者を追加管理者にする運用が必要です。

### 推奨構成

- ISPルーターまたは別置きルーター
- Instant On対応PoEスイッチ
- AP22×4、または後継同等機×4
- CAT6A有線バックホール
- 1階2台、2階2台を基本に、現場調査で位置調整

### 概算

2025年カタログ価格は次のとおりです。

- AP22：税別43,000円／台
- AP25：税別75,000円／台

したがって機器定価ベースでは、

- AP22×4：約18.9万円（税込）
- AP25×4：約33万円（税込）
- PoEスイッチ：約4万～10万円
- ルーター：約2万～8万円

実勢を含む構成概算は、

- AP22構成：約20万～30万円
- AP25構成：約35万～50万円

です。配線工事、ラック、UPS、設定費は別です。

AP22はWi-Fi 6であり、2026年の新築標準として最先端ではありません。しかし、住宅での実効性能、安定性、価格、保守性を考えると、Wi-Fi 7であることより適切なAP配置の方が重要です。

## Yamaha WLX＋RTX

### 工務店標準仕様としての適性

工務店がネットワーク施工会社と保守契約を組めるなら、標準仕様として最も保守しやすい候補です。

- 国内法人向け流通が安定
- 施工会社・SIerが扱いやすい
- RTXルーター、SWXスイッチ、WLX APを同一メーカーで構成可能
- 設定のバックアップ、交換、遠隔管理を標準化しやすい
- 天井設置、PoE給電に適合
- 長期保守向け
- 法人回線、VPN、複数SSID、VLANとの親和性が高い

一方で、施主自身が管理するには向きません。RTXの設定は家庭用ルーターより難しく、WLXも設計・施工側の知識を前提とします。

「保守担当者なし」でYamahaを入れると、壊れたときに誰も設定を復元できない構成になり得ます。したがって、保守契約なしの一般住宅には過剰です。

### 2026年7月の価格

- RTX840：136,400円
- RTX1300：295,900円
- WLX222：90,200円／台
- WLX322：129,800円／台
- WLX323：159,500円／台
- SWX2221P-10NT：223,300円

- RTX830：約69,600円
- WLX222：約55,200円

### 構成概算

#### 1Gbps級の住宅

- RTX830またはRTX840

- WLX222×4

機器実勢概算：約35万～50万円。

#### 10Gbps・2.5GbEを重視

機器概算：約75万～120万円。

住宅用途では、RTX1300＋WLX323×4は費用対効果が低い可能性があります。10Gbps回線、NAS、複数VLAN、監視カメラ、在宅業務などの要件がある場合に限定すべきです。

# 3. UniFiは一択に近づくか

一択にはなりません。

## UniFiが有力になる条件

- 中国ブランドだけを除外
- 保守担当者または施工会社がいる
- 2.5GbE、Wi-Fi 7、VLAN、監視、ログを重視
- カメラや入退室管理まで同一基盤に統合したい
- 機器費をYamahaより抑えたい

前回構成の2026年7月時点の公式税込価格は、確認できた範囲で次のとおりです。

- Cloud Gateway Fiber：46,545円
- Pro Max 16 PoE：67,636円
- U7 Lite：概ね18,000円台
- U7 Pro：概ね3万円前後

Cloud Gateway Fiberの公式価格は[Ubiquiti日本ストア](https://jp.store.ui.com/jp/en/category/all-cloud-gateways)、Pro Max 16 PoEは[製品ページ](https://jp.store.ui.com/jp/ja/products/usw-pro-max-16-poe)で確認できます。

AP×4を含む機器合計は概ね19万～25万円です。ラック、UPS、パッチパネル、設定、施工は別です。

価格性能比では依然としてUniFiが強い一方、障害時に施主だけで切り分ける構成ではありません。

## Instant OnがUniFiより有力になる条件

- 日常的な保守担当者はいない
- ただし初期施工と故障交換を行う業者は確保できる
- カメラ等の統合は不要
- Wi-Fi設定を簡素化したい
- Wi-Fi 6で足りる
- AP品質と天井設置を優先する

この住宅では、最もバランスがよい選択です。

## YamahaがUniFiより有力になる条件

- 工務店が複数住宅へ標準展開する
- 指定施工会社が存在する
- 設定テンプレート、予備機、交換手順を標準化する
- 長期保守費を販売価格に含める
- 施主が国産ブランドを強く要求する

単発住宅で保守契約なしなら、Yamahaは過剰です。工務店の標準商品として反復導入するなら意味があります。

# 4. 最終推奨

## A. 日常の保守担当者はいないが、工務店または電気工事会社が初期設定・故障交換を担当する

**第一推奨：HPE Networking Instant On AP×4**

推奨構成：

- AP22または現行同等機×4
- Instant On PoEスイッチ
- ルーターはISP機器または別置き
- CAT6Aスター配線
- 1階2台、2階2台
- 予備天井配線2箇所
- 施主所有のクラウドアカウント
- 施工会社を追加管理者に登録

これが今回の「Deco代替」に最も近い回答です。家庭用メッシュより施工品質を安定させやすく、UniFiより設定項目が少なく、ライセンス費もありません。

## B. 保守担当者が完全におらず、施主が家電として交換する

**第一推奨：BuffaloまたはNECを同一機種3～4台、有線バックホール**

ただし、設計を天井AP方式から変更します。

- 各階2台程度
- 棚上または造作収納の開放部に設置
- 各設置点にLAN＋AC100V
- 天井裏や金属製情報盤内には入れない
- 同一型番で統一
- 設定バックアップと交換手順書を引渡し

AtermとBuffaloの優先順位は僅差です。Atermは2026年時点で一部の有線メッシュ組み合わせに不安定性の注記があるため、工務店の標準化という観点では、現時点ではBuffaloを先に実機検証する方がよいです。

Orbiは性能上は候補ですが、日本での正規入手性と価格が弱いため標準仕様にはしません。

## C. 保守担当者またはネットワーク施工会社がいる

**第一推奨：UniFi**

- Cloud Gateway Fiber
- Pro Max 16 PoE
- U7 LiteまたはU7 Pro×4
- CAT6A
- 予備配線2箇所

価格性能比、可視化、拡張性では最も強い構成です。

ただし、「完成品も中国製造不可」であれば、納入ロットの原産国確認を通過するまで採用確定できません。

## D. 工務店が高価格帯住宅向け標準仕様として継続販売する

**第一推奨候補：Yamaha**

ただし、次をセットにする必要があります。

- 指定施工会社
- 標準コンフィグ
- 竣工時の電波測定
- 設定バックアップ
- 予備APまたは交換手配
- 5年程度の保守窓口
- 機器更新方針

この体制がないなら、Yamahaを採用する意味は薄くなります。

# 推奨順位

「中国ブランド除外」という意味なら、今回の順位は次です。

1. **施工会社による軽保守あり：HPE Networking Instant On**
2. **専門保守あり：UniFi**
3. **施主だけで運用：Buffalo／NECの有線メッシュ**
4. **工務店の長期標準仕様：Yamaha**
5. **Orbi：国内流通と価格の理由で見送り**
