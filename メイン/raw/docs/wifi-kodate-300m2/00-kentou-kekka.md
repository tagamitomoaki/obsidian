# 戸建て住宅（2階建て・延床300㎡）Wi-Fi設計 検討結果

- 作成日: 2026-07-25
- 検討: Claude（調査・取りまとめ）× Codex（独立検討3ラウンド、詳細は同フォルダ01〜03）
- 価格はすべて2026年7月25日時点の確認値。発注時に要再確認

## 1. 前提条件

| 項目 | 内容 |
|---|---|
| 建物 | 2階建て戸建て、延床300㎡（各階約150㎡） |
| 回線 | フレッツ光系（1G or 10G）を想定 |
| 施主 | 一般利用者（IT知識なし）。ChatGPTにUniFiを推奨され、積水ハウス施主のUniFiフル導入note記事に影響を受けている |
| 工務店 | IT専業ではない。代表が「ちょっと詳しい」程度（家庭用ルーター設定・スマホアプリ管理は可、CLIや深い切り分けは不可） |
| 専門保守契約 | なし |
| 施主の制約 | 中華製は嫌 → **中国ブランド（TP-Link等）除外**として解釈（製造国まで除外するとほぼ全メーカーが脱落し非現実的。UbiquitiもEMS生産で製造国はロット依存） |

## 2. 結論

**第一候補: UniFi AP-only簡素構成**（ゲートウェイなし。HGWがルーティング担当）

分岐条件:

- 施主が入居時からカメラ・ドアベルまで導入 → この構成のままUniFi Protectへ拡張
- 施主が「カメラ不要・とにかく壊れず簡単に」 → **HPE Instant On**（Codex推奨案）に切り替え

どちらに転んでも建築仕様（§4）は同一なので、配線工事を先に確定し、機器は後決めで間に合う。

### CodexとClaudeの見解相違について

最終ラウンドでCodexはInstant On、ClaudeはUniFiを推した。ただしCodexの批判は「HGW配下にUCG（UniFiゲートウェイ）を追加すると、価値を抑制しながら故障点だけ増える」という点に向いており、**ゲートウェイを入れないAP-only構成なら批判の大半は解消**する（トポロジーはCodexのInstant On案と同型: HGW→PoEスイッチ→AP×4）。

残る実質差は2点のみ:

- **機器交換の簡単さ**: Instant Onが上（設定がHPEクラウド側に残り「新品購入→アプリ再登録」で完結。UniFiはバックアップ復元の作法が必要）
- **施主の納得感・将来のカメラ統合・Wi-Fi 7**: UniFiが上

UniFiを第一候補とする決め手は顧客関係の力学。施主は自分で調べてUniFiに行き着いており、別ブランドを勧めて後日不満が出ると「だからUniFiと言ったのに」になる。UniFiなら不具合時も「自分が選んだもの」として納得が得られやすい。

## 3. 構成案

### 案1（第一候補）: UniFi AP-only簡素構成 — 機器約20〜23万円

```text
光回線 ── HGW（既設・ルーティング/IPoE担当）
              │
        UniFi PoEスイッチ（USW Pro Max 16 PoE）
              ├─ U7 Pro（1階中央・天井）
              ├─ U7 Pro（2階中央・天井）
              ├─ U7 Lite（補完1）
              ├─ U7 Lite（補完2）
              └─ Cloud Key Gen2 Plus（管理コンソール・ラック内）
```

| 機器 | 型番 | 台数 | 単価（税込） | 小計 |
|---|---|---:|---:|---:|
| ルーター | 既設HGW | 1 | 0円 | 0円 |
| PoEスイッチ | USW-Pro-Max-16-PoE | 1 | 67,636円 | 67,636円 |
| 管理コンソール | UCK-G2-PLUS | 1 | 3〜4万円（要確認） | 約35,000円 |
| AP（各階中央） | U7 Pro | 2 | 30,364円 | 60,728円 |
| AP（補完） | U7 Lite | 2 | 16,818円 | 33,636円 |
| 合計 | | | | **約20万円** |

- 二重NATなし・追加ルーターなし。IPoE/MAP-E問題はHGW側に完結
- コンソール故障時もAPは最終設定で動作継続（Wi-Fiは止まらない）
- UCK-G2-PLUSはNetwork+Protect同梱・1TB HDD内蔵 → 将来カメラ・ドアベルを同じスイッチに挿すだけで録画まで対応（最新カメラの対応可否は導入時にロードマップ要確認）
- VLANなし・SSID 1〜2個・自動クラウドバックアップON・ファーム更新は手動承認
- 本格統合（UCG-Fiber等への移行）は保守担当を確保できた時点で検討

### 案2（分岐先）: HPE Instant On — 機器約18.3万円（定価ベース）

| 機器 | 型番 | 台数 | 単価（税別定価） | 小計（税込換算） |
|---|---|---:|---:|---:|
| ルーター | 既設HGW | 1 | 0円 | 0円 |
| PoEスイッチ | Instant On 1930 24G PoE 195W（JL683B#ACF） | 1 | 78,000円 | 約86,000円 |
| 天井AP | Instant On AP22（R6R77A、JP） | 4 | 22,000円 | 約97,000円 |
| 合計 | | | | **約183,000円** |

- 管理はアプリ/クラウドポータル/ローカルWeb GUI。ライセンス・管理費無料
- AP22はWi-Fi 6（2×2）。300㎡ではAP単体の速度より4台の配置が支配的で実用十分
- 機器交換は「新品購入→アプリ再登録」で完結。専門保守なし運用に最適
- 将来UniFi Protectが欲しくなった場合も、Protectコンソール＋カメラを同一LANに追加する混在構成が可能（管理画面は分かれる）

### 不採用とした案

| 案 | 理由 |
|---|---|
| UDM-SE中心のフルUniFi（note記事構成） | カメラ統合＋保守担当がいる場合の構成。現体制では過剰 |
| TP-Link Deco / Omada | 施主意向（中国ブランド除外） |
| NEC Aterm / Buffalo 有線メッシュ | 天井設置・PoE不可で建築計画と不整合。有線メッシュの安定性に注記あり。完全に施主任せの場合の最終フォールバック |
| Netgear Orbi | 日本の正規流通・価格が不安定 |
| ヤマハ RTX + WLX | 単発案件では過剰（機器35万円〜）。工務店が高価格帯住宅の標準仕様として反復展開＋保守窓口を整備するなら最有力 |

## 4. 建築仕様（製品非依存・先行確定可）

機器選定と独立に、新築時に必ず施工する。機器より配線の方が住宅寿命に近く、後からの修正費用が大きい。

- **CAT6Aスター配線**: 全配線を情報ラックへ集約。数珠つなぎ禁止。ジャック・パッチパネルもCAT6A対応、配線試験実施
- **天井AP用配線**: 6箇所（稼働4＋予備2）。各階2箇所＋予備1箇所。予備位置は吹抜け・廊下中央・LDK反対側など実測後に選べる場所。天井裏の位置を図面と写真で記録
- **天井AP候補位置の近くにAC電源**（将来据置型メッシュに変更する場合の保険）
- **居室配線**: 各居室2口以上、書斎・リビングTV周り4〜6口。TV・ゲーム機・PC・NASは有線化
- **情報ラック**: 住宅用情報分電盤ではなく19インチラック（奥行450mm以上・換気・専用コンセント・UPSスペース）。PoEスイッチのファン音に注意し設置場所を選定
- **空配管**: 引込点→ラック、ラック→各階天井裏・書斎・TV位置・門柱・ガレージ。呼び線を残す
- **屋外**: カメラ候補位置・インターホンへCAT6A各1本。別棟・ガレージは光ファイバーを通せる配管径で

## 5. 引き渡し条件（書面化必須）

1. **UIアカウント（またはHPEアカウント）は施主がOwner**。工務店代表は管理者として招待される形。多要素認証ON
2. **自動バックアップON＋復旧手順書を紙でラック内に掲示**（再起動順序: HGW→スイッチ→AP。案1の場合はゲートウェイ相当なしなので、コンソール障害時の「Wi-Fiは動き続ける」旨も明記）
3. **引き渡し後の障害対応は有償（またはベストエフォート）と明記**。免責範囲・対応時間を契約書に

引き渡し資料: 論理構成図・配線系統図・LAN口番号とパッチパネル対応表・壁閉じ前の配線写真・配線試験結果・機器シリアル・購入先と保証期限・設定バックアップ・SSID一覧。パスワードの平文印刷は避け、施主のパスワード管理手段へ移管。

## 6. 施主への説明論点

1. note記事の構成は「保守できる施主」が前提。機器を同じにしても保守体制まで同じにはならない
2. U6+×2台（各階1台）を300㎡に流用するのは危険。AP4台＋予備配線2箇所が設計標準
3. 「中華製除外」はブランド基準で運用（TP-Link等除外）。製造国基準ではUbiquiti含めほぼ全滅するため非現実的
4. 決めるべきは「カメラ・ドアベルをいつ入れるか」だけ。入居時から→案1で拡張 / 当面Wi-Fiのみ→案1（将来拡張可）or 案2（交換の簡単さ優先）
5. 10G回線でも全端末10Gにはならない。基幹10G・AP 2.5G・一般端末1Gの設計が費用対効果に合う
6. 竣工後に電波実測し、弱い場所があれば予備配線にAPを追加
